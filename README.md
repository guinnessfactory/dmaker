# DSHOP D-Maker

DSHOP 배너·상품 이미지를 사이즈별로 크롭하고 문구를 얹어 저장하는 웹 도구입니다. 서버 없이 정적 파일만으로 동작합니다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 화면 구성 |
| `style.css` | 스타일 |
| `script.js` | 편집 기능 전체 |
| `sizes.json` | **팀 공용 기본 사이즈 목록** |

## 사이즈 관리

### 각자 화면에서 조정 (개인 설정)
왼쪽 **사이즈 관리** 패널에서 다음 작업을 할 수 있습니다.
- 이름·너비·높이 수정: 입력 후 Enter를 누르거나 다른 곳을 클릭하면 바로 적용됩니다.
- 기본 텍스트 배치 선택: `T 가운데`, `T 왼쪽`, `T 없음`
- ↑ ↓ 버튼으로 순서 변경, ✕ 버튼으로 삭제
- **＋ 새 사이즈 추가**로 원하는 사이즈 추가

수정 내용은 브라우저(localStorage)에 자동 저장되고, 배지에 `수정됨`이 표시됩니다. 사이즈를 바꿔도 이미 잡아둔 구도와 텍스트는 비율에 맞춰 유지됩니다.

### 팀 전체 기본값 변경
1. 화면에서 사이즈를 원하는 대로 맞춘 뒤 **내보내기**를 누르면 `sizes.json` 파일이 저장됩니다.
2. 저장된 파일로 저장소의 `sizes.json`을 교체하고 커밋·배포합니다.
3. 개인 수정본이 없는 사용자는 바로 새 기본값을 보게 됩니다. 개인 수정본이 있는 사용자는 **팀 기본값으로 복원**을 누르면 새 기본값으로 바뀝니다.

`sizes.json` 형식은 다음과 같습니다.
```json
{ "sizes": [ { "id": "main", "label": "메인 배너", "w": 750, "h": 750, "textLayout": "center" } ] }
```
- `w`, `h`: 10~5000 사이의 px 값
- `textLayout`: `center`, `left`, `none` 중 하나

## 로컬 실행
`sizes.json`을 fetch로 읽기 때문에 로컬 서버로 여는 것을 권장합니다.

```bash
python3 -m http.server 8000
# http://localhost:8000
```

index.html을 파일로 바로 열어도 동작합니다. 이때 `sizes.json`을 읽지 못하므로 script.js에 내장된 기본값이 쓰입니다.
